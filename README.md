# MosTransport: тренажёр проводника ВСМ

Тренажёр для проводников поезда ВСМ «Москва - Санкт-Петербург». Игрок ходит по вагону от первого лица, разговаривает с пассажирами и принимает решения в нештатной ситуации. Каждое решение влияет на шкалы лояльности пассажиров и безопасности, в конце показывается разбор с оценками и комментариями.

Видео-демонстрация работы приложения: https://disk.yandex.ru/d/i5YsEhnLjBOb5w

## Сценарии

| Сценарий | Навыки | Состояние                               |
|---|---|-----------------------------------------|
| «Бесхозная вещь» | безопасность, управление паникой, поиск владельца, работа с фактами | играбельный, несколько вариантов сюжета |
| «Пассажиру плохо» | первая реакция, организация помощи, работа с окружающими | в работе                                |

## Запуск готовой сборки

Windows: [docs-dev/Readme-Run-Windows.md](docs-dev/Readme-Run-Windows.md).

Браузер: [docs-dev/Readme-Run-WebGL.md](docs-dev/Readme-Run-WebGL.md).

Управление: 
- `WASD` и мышь, 
- `Shift` бег, 
- `E` действие, 
- `G` стрелка к цели, 
- `1` терминал ММТ, 
- `2` рация, 
- `F` / ПКМ свободный курсор, 
- `Esc` / `Tab` пауза.

## Запуск из редактора

1. Unity **6000.4.1f1** (Unity 6.4).
2. Открыть сцену `Assets/VSM/Scenes/VSM_Menu.unity`, нажать Play, выбрать карточку сценария и «Начать».
3. Сцена поезда: `Assets/VSM/Scenes/VSM_Train_Bag.unity`.

Тесты: Test Runner, EditMode, сборка `Game.Scenarios.Tests`.

## Структура

| Путь | Что там                                                                                   |
|---|-------------------------------------------------------------------------------------------|
| `Assets/Scripts/Scenarios/Core` | движок сценариев: core, граф узлов, переменные, шкалы, оценки (без зависимостей от сцены) |
| `Assets/Scripts/Scenarios/Presentation` | диалоги, HUD, меню, разбор, актёры и объекты в мире                                       |
| `Assets/Scripts/Scenarios/Editor` | тулзы, UI, меню, персонажи, сценарии (меню `Game/Scenarios`)                              |
| `Assets/Scripts/Characters` | пассажиры: логика, рассадка, анимации, лицо, внешность                                    |
| `Assets/Data/Scenarios` | сценарии (`*.json`, SO), составы актёров (`Casts/`), строки UI (`Ui/`)                    |
| `Assets/VSM` | модель поезда, сцены меню и вагонов                                                       |
| `docs-dev` | материалы для разработки                                                                  |

## Технологии

Unity 6 (URP), Input System, Cinemachine, VContainer, MessagePipe, UniTask, R3, DOTween, Odin Inspector, TextMesh Pro. Персонажи: CharacterCustomizer и анимации Mixamo.
