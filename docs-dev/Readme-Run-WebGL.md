# Запуск в браузере (WebGL)

Веб-версия тренажёра.

Ссылка: https://vsm-trainer.website.yandexcloud.net/

## Рекомендуемая конфигурация

Рекомендуется открывать на **компьютере (ПК или ноутбук)** в свежей версии **Google Chrome**, **Microsoft Edge** или **Яндекс Браузера**.

- Компьютер с Windows, macOS или Linux, клавиатура и мышь.
- Не меньше 8 ГБ оперативной памяти: в браузере тренажёр может занимать до 2 ГБ.
- Видеокарта с поддержкой WebGL 2.0 (подойдёт любая видеокарта последних лет, включая встроенную).
- Стабильный интернет для первой загрузки (около 190 МБ).

## Первая загрузка и кэш

Первое открытие может занять **от нескольких десятков секунд до нескольких минут**: браузер скачивает около 190 МБ данных. Прогресс показывается полосой на заставке. Не закрывайте и не обновляйте вкладку, пока загрузка не дойдёт до 100% и не появится кнопка «Начать».

После первой загрузки данные сохраняются в кэше браузера. Следующие запуски на этом же компьютере и в этом же браузере проходят заметно быстрее: браузер только сверяет файлы с сервером и не скачивает их заново.

Кэш не работает в режиме инкогнито и сбрасывается при очистке данных сайтов. Тогда загрузка снова будет долгой.

## Запуск

1. Откройте ссылку в рекомендуемом браузере.
2. Дождитесь, пока полоса загрузки дойдёт до 100%.
3. Нажмите **«Начать»**. Тренажёр откроется во весь экран.
4. В меню выберите карточку сценария и нажмите «Начать».

`Esc` выходит из полноэкранного режима, следующий щелчок по игре возвращает его. Закрыть тренажёр можно, просто закрыв вкладку.

## Управление

| Клавиша | Действие |
|---|---|
| W A S D | идти |
| Мышь | осмотреться |
| Shift | бежать |
| E | действие: заговорить, выбрать |
| G | жёлтая стрелка к цели |
| 1 | терминал ММТ |
| 2 | рация |
| F / ПКМ | свободный курсор |
| Tab | пауза, описание и управление |
| Esc | в полноэкранном режиме сначала выходит из него (так устроен браузер), повторное нажатие открывает паузу |

С чего начать: в меню выберите карточку сценария и нажмите «Начать». В вагоне идите по жёлтой стрелке на полу к пассажиру, посмотрите на него и нажмите E.

## Частые проблемы

- **Загрузка идёт очень долго или застыла.** Проверьте интернет и подождите: на медленном соединении 190 МБ качаются несколько минут. Если полоса не двигается совсем, обновите страницу.
- **Сообщение «Не удалось запустить тренажёр» или вкладка упала.** Чаще всего браузеру не хватило памяти. Закройте лишние вкладки и программы и откройте ссылку снова. На телефоне попробуйте компьютер.
- **Чёрный экран или ошибки графики.** Обновите браузер и драйверы видеокарты. Проверьте, что в настройках браузера включено аппаратное ускорение. Проверить поддержку WebGL 2.0 можно на https://get.webgl.org/webgl2/
- **Низкая частота кадров.** Закройте другие вкладки, особенно с видео. На ноутбуке подключите зарядку: без неё браузер часто работает на встроенной видеокарте и в режиме экономии энергии.
- **Не работает полноэкранный режим.** Щёлкните по игре ещё раз. В Safari на iPhone полноэкранного режима нет.
- **После обновления тренажёра видна старая версия.** Обновите страницу с очисткой кэша: `Ctrl + F5` (на macOS `Cmd + Shift + R`).

## Совместимость с браузерами

Веб-версия работает внутри браузера, и её поведение зависит от браузера, его версии и видеокарты. На разных браузерах возможны проблемы совместимости.

| Браузер | Состояние |
|---|---|
| Google Chrome, Microsoft Edge, Яндекс Браузер (ПК) | рекомендуется |
| Mozilla Firefox (ПК) | должен работать, возможна более низкая частота кадров |
| Safari (macOS) | возможны проблемы с графикой и полноэкранным режимом |
| Телефоны и планшеты | не рекомендуется: мало памяти, долгая загрузка, управление рассчитано на клавиатуру и мышь |

Совместимость дорабатывается в процессе разработки: найденные проблемы исправляются, и список поддерживаемых браузеров со временем будет расширяться.

Если в одном браузере что-то работает неправильно, попробуйте другой из рекомендуемых. Для самой стабильной работы лучше [версия для Windows](Readme-Run-Windows.md).
