# Запуск на Windows

Сборка тренажёра для Windows 10 и 11 (64-bit). Установка не нужна: архив распаковывается и запускается.

## Системные требования

- Windows 10 или 11, 64-bit.
- Около 1 ГБ свободного места после распаковки.
- Клавиатура и мышь.

## Запуск

1. Скачайте архив `MosTransport.zip`:
    - GitHub https://github.com/Ext1se/mt-hackathon 
    - или Yandex Disk: https://disk.yandex.ru/d/BO6P6M7GsbRT5g.
2. **До распаковки** снимите с архива метку "загружено из интернета" (см. раздел ниже, способ 1). Тогда Windows не будет спрашивать про каждый файл.
3. Распакуйте архив целиком в обычную папку, например `C:\Games\MosTransport`. Не запускайте игру прямо из архива: без распаковки она не найдёт свои данные.
4. Запустите `Hack_MosTransport.exe`.
5. Игра открывается в развёрнутом окне. `Alt + Enter` переключает полноэкранный режим, `Alt + F4` закрывает игру.

## Если Windows не даёт запустить программу

К сожалению, текущаю дев-сборка не подписана цифровой подписью (сертификат разработчика еще оформляется). Поэтому фильтр SmartScreen видит "неизвестного издателя" и предупреждает. Это не значит, что в файле вирус: так Windows реагирует на любую новую неподписанную программу.

### Способ 1. Разблокировать архив до распаковки (рекомендуется)

1. Щёлкните правой кнопкой по `MosTransport.zip` и выберите **Свойства**.
2. Внизу вкладки **Общие** поставьте галочку **Разблокировать** и нажмите **ОК**.
3. Теперь распакуйте архив. Файлы из разблокированного архива не получают метку, и предупреждение обычно не появляется.

Если галочки «Разблокировать» нет, метки на файле нет, и этот шаг можно пропустить.

### Способ 2. Окно «Система Windows защитила ваш компьютер»

1. В синем окне нажмите ссылку **Подробнее**.
2. Появится строка «Издатель: неизвестный издатель» и кнопка **Выполнить в любом случае**. Нажмите её.
3. Windows запомнит выбор, и при следующих запусках окно не появится.

### Способ 3. Разблокировать уже распакованный exe

Если архив распакован без разблокировки: **Свойства** у `Hack_MosTransport.exe`, галочка **Разблокировать**, **ОК**. Или в PowerShell в папке с игрой:

```powershell
Get-ChildItem -Recurse | Unblock-File
```

### Если файл удалил антивирус

Встроенный Защитник Windows иногда ошибочно помещает новые неподписанные программы в карантин.

1. Откройте **Безопасность Windows**, раздел **Защита от вирусов и угроз**, затем **Журнал защиты**.
2. Найдите запись с `Hack_MosTransport.exe`, выберите **Действия**, затем **Разрешить** или **Восстановить**.

Не отключайте Защитник целиком: достаточно разрешить этот файл. И делайте это только для архива, скачанного со страницы Releases нашего репозитория.

## Управление

| Клавиша | Действие |
|---|---|
| W A S D | идти |
| Мышь | осмотреться |
| Shift | бежать |
| E | действие: заговорить, выбрать |
| G | жёлтая стрелка к цели |
| 1 | терминал ММТ |
| 2 | рация |
| F / ПКМ | свободный курсор |
| Esc / Tab | пауза, описание и управление |

С чего начать: в меню выберите карточку сценария и нажмите «Начать». В вагоне идите по жёлтой стрелке на полу к пассажиру, посмотрите на него и нажмите E.

## Частые проблемы

- **Игра не запускается, окно сразу закрывается.** Проверьте, что архив распакован целиком и рядом с exe лежат папки `Hack_MosTransport_Data`, `MonoBleedingEdge` и `D3D12`, а также `UnityPlayer.dll`.
- **Чёрный экран или ошибка графики.** Вероятно, проблемы драйверов видеокарты.
- **Путь с кириллицей.** Если игра ведёт себя странно, попробуйте папку с латинским путём, например `C:\Games\MosTransport`.
